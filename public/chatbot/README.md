# Landing Chatbot Content

هذا المجلد مخصص لتعديل سلوك شات بوت صفحة الهبوط بدون تعديل الكود.

## الملفات
- `knowledge-base.md`: معلومات المنتج والأسئلة الشائعة التي يعتمد عليها الشات بوت.
- `system-instructions.md`: تعليمات سلوك الشات بوت.
- `fallback-message.md`: الرسالة التي تظهر عندما لا توجد إجابة داخل قاعدة المعرفة.
- `social-intents.md`: ردود جاهزة للتحية والمجاملة والأسئلة الاجتماعية البسيطة.

## طريقة التحديث
1. عدّل أي ملف هنا.
2. محليًا (`npm run dev`): التغيير ينعكس مباشرة في الطلبات الجديدة.
3. على البيئة المنشورة: ادفع التعديلات ثم أعد النشر (`npm run deploy`) لتطبيقها.
